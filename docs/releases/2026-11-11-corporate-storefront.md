# Corporate multi-brand storefront

The public JewelTime watch storefront now opens with the company's brand portfolio instead of a single featured product. Visitors can browse ten brand categories, view the wider catalogue and find the representation inquiry form from clear page sections. The form's visual presentation and file-selection text were also cleaned up.

The live release was checked at mobile and desktop widths in light and dark browser preferences. The homepage showed one clear heading, all ten brand routes responded, and there was no horizontal overflow. The mobile menu expanded, search received focus and file selection showed the selected filename. No purchase or inquiry was submitted. Product and checkout operations were outside this presentation update.
